# Triage (TaskNotes Edition)

Move TaskNotes-formatted issues and tasks (and optional external PRs) through a state machine of triage roles.

Every comment or issue posted during triage **must** start with this disclaimer:

```
> *This was generated by AI during triage.*
```

## Reference docs

- [AGENT-BRIEF.md](AGENT-BRIEF.md): how to write durable agent briefs
- [OUT-OF-SCOPE.md](OUT-OF-SCOPE.md): how the `thoughts/out-of-scope//` knowledge base works

## Roles

- **Categories**: `bug`, `enhancement`
- **States**: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`

Role mapping and label strings are defined in `docs/agents/triage-labels.md` (configured via `/setup-skills`).

## Process

1. **Show Attention**: Query the issue tracker (TaskNotes files under `thoughts/` or configured tracker) and categorize items into unlabeled, `needs-triage`, and `needs-info`.
2. **Triage Specific Task/Issue**: Read context, verify claims against the codebase, grill if necessary, and apply the appropriate outcome state (e.g. `ready-for-agent` with an agent brief).
3. **TaskNotes Alignment**: Ensure all tasks and tickets adhere strictly to the TaskNotes specification (YAML frontmatter with `title`, `status`, `priority`, `tags`, `blockedBy`, `dateCreated`, `dateModified`).
